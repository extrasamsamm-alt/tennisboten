# Tennisboten

Hittar ATP-matcher på Polymarket där statistikmodellen ser edge, och låtsasspelar dem.
Körs automatiskt varje timme av GitHub Actions. Inga riktiga order, ingen nyckel, ingen wallet.

* Sidan med signaler: se länken under Settings → Pages.
* Låtsasbeten: `data/paper/bets.jsonl`.
* Statistik: TML-databasen (stats.tennismylife.org), ej för kommersiellt bruk.
